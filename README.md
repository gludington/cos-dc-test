# Campaign Blog

A static site that publishes in-character session notes from a Foundry VTT campaign, generated by
the Wikiworld Sync Foundry module. You don't edit anything in this repo by hand — Foundry pushes
new posts here directly, and your host rebuilds the site automatically.

## First-time setup

1. **Create your own copy of this repo**: click the green **"Use this template"** button at the
   top of this page (not "Fork" — that keeps you independent, no link back to the original).
   Name it whatever you like, e.g. `my-campaign-blog`.
2. **Generate a token so Foundry can push here**: on your new repo, go to your GitHub profile
   picture → **Settings → Developer settings → Personal access tokens → Fine-grained tokens →
   Generate new token**. Restrict it to just this repo, and under Permissions set **Contents** to
   **Read and write**. Copy the token — you won't see it again.
3. **Connect a host** so the site actually goes live. Either works the same way:
   - **Cloudflare Pages**: dashboard → Workers & Pages → Create → Pages → Connect to Git → pick
     this repo → build command `npm run build`, output directory `dist` (leave root directory
     blank/`.`) → Deploy.
   - **Netlify**: Add new site → Import an existing project → Deploy with GitHub → pick this repo
     → build command `npm run build`, publish directory `dist` → Deploy.
4. **Tell the Foundry module about this repo**: in Foundry, **Configure Settings → Wikiworld
   Sync**, fill in your GitHub username, this repo's name, the branch your host builds from
   (usually `main`), and the token from step 2.

From here on: write in Foundry, click **Publish** on a page, click **Publish to GitHub** — your
host picks up the new commit and rebuilds automatically. Nothing in this repo needs manual
editing, ever.

## What's in here

- `src/` — the Astro site (pages, layout, content collection config)
- `content/` — generated markdown, one file per published post. Written by the Foundry module,
  not by hand.

## Local development (optional, not needed for normal use)

```sh
npm install
npm run dev
```
